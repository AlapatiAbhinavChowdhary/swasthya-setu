# Project instructions

Read `docs/HANDOFF.md` first.

- This is an awareness chatbot, not a diagnosis or prescription service.
- Accept only verified Indian government or WHO sources.
- Never invent facts or silently fill missing coverage.
- Emergency detection and localized safety messages are deterministic.
- The owner runs no commands or edits; run and verify everything autonomously.
- Report exact command output before marking work complete.
- Work on a phase branch, make small conventional commits, then merge after checks.
- Never commit API keys, `.env`, PDFs, vectorstores, databases, or generated caches.
